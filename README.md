# IgHakerBot

**IgHakerBot** is a Python-based automation tool designed to interact with Instagram accounts. It offers functionalities such as liking posts, following users, and posting comments automatically. This tool is intended for educational purposes and personal account management. Users must ensure compliance with Instagram's [Terms of Use](https://help.instagram.com/581066165581870) and avoid activities that could be considered spamming or unauthorized access.

## Features

- **Automated Liking**: Automatically like posts based on hashtags, locations, or user profiles.
- **Auto-Follow**: Follow users who post content relevant to specified hashtags or locations.
- **Commenting**: Post predefined comments on posts to increase engagement.
- **Unfollow**: Identify and unfollow users who do not follow back after a certain period.
- **Activity Logs**: Maintain logs of actions performed for monitoring and analysis.

## Installation

1. **Clone the Repository**:

   ```bash
   git clone https://github.com/Tirthaboss/IgHakerBot.git
   ```


2. **Navigate to the Project Directory**:

   ```bash
   cd IgHakerBot
   ```


3. **Install Dependencies**:

   ```bash
   pip install -r requirements.txt
   ```


## Usage

1. **Configuration**:

   - Rename `config_sample.json` to `config.json`.
   - Update `config.json` with your Instagram credentials and desired settings.

2. **Running the Bot**:

   ```bash
   python ighakerbot.py
   ```


   The bot will start performing actions based on your configuration.

## Important Notice

While IgHakerBot provides automation capabilities, it's crucial to use it responsibly:

- **Account Safety**: Excessive automation can lead to account suspension or banning.
- **Ethical Use**: Use the bot only on accounts you own or have explicit permission to manage.
- **Compliance**: Ensure all actions comply with Instagram's [Community Guidelines](https://help.instagram.com/477434105621119).

For more information on Instagram's policies and how to protect your account, refer to the [Instagram Help Center](https://help.instagram.com/).
